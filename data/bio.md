Hemanth is an Associate Manager at Temus Pte. Ltd. in Singapore, recently promoted from Senior Data Engineer. He works on AI integration and large-scale data engineering projects, including a collaboration with A*STAR's Bioinformatics Institute on the SNPDrug3D genomics platform.

## Career arc

- **2017 – 2021** — Associate Software Engineer, **JP Morgan Chase Singapore**. Built and maintained a Java Spring Boot liquidity reporting platform serving global clients, including a Report Orchestration engine using multi-threading and CompletableFuture, BIRT-templated reports, and Angular UIs for the operations team.
- **Dec 2021 – Jun 2022** — Associate Software Engineer, **GIC Pte Ltd**. Internal portfolio risk management system in Scala / Java, integrating MSCI's BarraOne risk platform alongside Zenika consultants.
- **Jul 2022 – May 2024** — Senior Data Engineer, **Singapore Press Holdings (Media)**. Led a three-person data engineering team, building AWS-based pipelines (Glue, EventBridge, S3, Athena), custom AppFlow connectors in Java for alternative data, and a Slack chatbot integrated with Google Gemini for natural-language-to-SQL reporting.
- **Jul 2024 – present** — Data Architect / Associate Manager, **Temus Pte. Ltd.**. SQL Server → Databricks Lakehouse migrations, geospatial pipelines for Laconic's carbon credit marketplace, and the SNPDrug3D variant-to-structure mapping platform with A*STAR.

## The throughline

Java banking development → cloud data engineering on AWS / Azure / Databricks → AI agent development and automation. The current focus is multi-agent orchestration, MCP-based integrations, and LLM-augmented data pipelines.

The longer-term goal is a "virtual wealth fund" of specialized autonomous agents producing real income — Decision Ledger and the alpaca-bot trading system are early candidates.
